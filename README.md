## Overview

This project is a simplified blockchain implementation that demonstrates the fundamental concepts of blockchain technology including:
- Block structure and hashing
- Transaction handling
- Mining process with Proof of Work
- Merkle Trees for transaction verification
- Chain validation and immutability

## Features

- **Complete Blockchain Implementation**: Genesis block creation, block mining, and chain validation
- **Transaction System**: Create and manage transactions with coinbase rewards
- **Merkle Trees**: Efficient transaction verification
- **RESTful API**: Full API for interacting with the blockchain
- **Interactive Web Interface**: Beautiful dashboard to visualize the blockchain
- **Real-time Updates**: Auto-refresh functionality
- **Tamper Detection**: Demonstrate blockchain immutability
- **Balance Tracking**: Calculate addresses balances
- **Multiple Transaction Support**: Batch transaction creation

## Technology Stack

- **Backend**: Node.js, Express.js
- **Cryptography**: SHA-256 hashing (crypto-js)
- **Frontend**: HTML5, CSS3, JavaScript
- **API**: RESTful architecture
